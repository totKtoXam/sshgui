# sshgui

Набор PowerShell-скриптов для Windows: меню SSH-подключений и «рабочий стол» для файлов на сервере.

## Состав

| Файл | Что делает |
|---|---|
| `ssh-menu.ps1` | Текстовое меню подключений (группы, цвета, поиск). Enter → выбор: терминал здесь, GUI-рабочий стол или вкладка Windows Terminal. Одновременно библиотека для остальных скриптов. |
| `ssh-menu-gui.ps1` | То же меню в окне WPF. |
| `ssh-desktop.ps1` | Файловый менеджер сервера в стиле Linux Mint (по sftp). |
| `connections.example.yml` | Пример конфига. Свой `connections.yml` лежит рядом со скриптами и не коммитится. |

## Требования

Windows 10/11, PowerShell 7+, OpenSSH-клиент (`ssh.exe`, `sftp.exe`). Windows Terminal — по желанию.

## Запуск

```powershell
cp connections.example.yml connections.yml
pwsh -NoLogo -File .\ssh-menu.ps1        # текстовое меню
pwsh -NoLogo -STA -File .\ssh-menu-gui.ps1   # меню-окно
```

Рабочий стол можно открыть из меню (Enter → G), либо напрямую:

```powershell
pwsh -NoLogo -STA -File .\ssh-desktop.ps1 -Name my-server -Address 192.168.0.10 -Port 22 -Login user
```

### Клавиши меню (TUI)

↑↓ выбор · Enter подключить · Ins/Ctrl+N новое · F2/Ctrl+E изменить · F3 цвет · F5 GUI-меню · Del удалить · Esc выход.

## Рабочий стол (`ssh-desktop.ps1`)

- Свободная раскладка значков, плавающие окна папок сервера, панель задач, часы.
- **Виртуальные папки и ярлыки** хранятся только локально (`desktops/<login@адрес_порт>.json`) — на сервере ничего не меняется.
- Виды: крупные / мелкие значки / список (размер, дата, тип). Сортировка по имени, размеру, дате, типу. Вид, сортировка и окна запоминаются.
- Всё управление — через ПКМ (фон, значок, меню «Пуск»).
- Загрузка файлов перетаскиванием в окно, скачивание, создание папки, переименование.
- **Мультивыделение:** Ctrl/Shift+клик, рамка выделения; групповые перенос, закрепление, копирование на ПК, удаление.
- **Поиск:** ПКМ по рабочему столу → «Найти…» (виртуальные объекты + сервер от домашней папки), ПКМ в окне сервера → «Найти на сервере…» (`find`, до 500 результатов).
- **Правка файла:** «Править» скачивает файл, открывает его, после сохранения предлагает загрузить обратно.
- **Ярлык Windows** рабочего стола для подключения — через меню «Пуск».

### Что меняет сервер, и как защищено

Любое изменение на сервере запрашивает подтверждение. Удаление папок выполняется `rm -rf --` по ssh только после ввода слова `УДАЛИТЬ`; пути не глубже двух уровней, относительные и с `..` отклоняются.

## Безопасность

- Пароли в `connections.yml` хранятся как `dpapi:…` (Windows DPAPI, привязка к пользователю и ПК). Файл не коммитьте.
- Пароль передаётся дочерним `ssh`/`sftp` через `SSH_ASKPASS` и переменную окружения процесса; на диск открытым текстом не пишется.
- Новые хосты принимаются автоматически (`StrictHostKeyChecking=accept-new`).

## Ограничения

Каждая sftp-операция — отдельный процесс (около 1,5 с задержки; постоянный канал невозможен из‑за буферизации вывода sftp). Симлинки показываются как папки. Конфликты при загрузке правки не отслеживаются. Поиск требует GNU `find` на сервере.
